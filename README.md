# DevConnector

DevConnector is a full-stack developer networking platform designed to help developers create professional profiles, connect with other developers, share posts, and interact with the community.

The project includes user authentication, profile management, developer connections, posts, comments, and RESTful APIs. It was built to practice and demonstrate real-world full-stack web development, backend API integration, database management, and secure authentication.

### Tech Stack

* **Frontend:** React.js
* **Backend:** Node.js, Express.js
* **Database:** MongoDB
* **Authentication:** JWT
* **API:** REST API

### Key Features

* User registration and login
* Developer profile creation and management
* Connect with other developers
* Create and share posts
* Like and comment functionality
* REST API integration
* Secure JWT-based authentication
* MongoDB database integration
